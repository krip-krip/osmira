# Osmira

Système de production vidéo à distance, construit par modules.

| Module | Rôle | État |
|---|---|---|
| **OsmiraCam** | Poste cadreur sur Raspberry Pi : affichage d'une caméra PTZ parmi plusieurs, bascule instantanée, pilotage à la manette | maquette validée (moteur vidéo) |
| **OsmiraCore** | Serveur central : configuration des postes, droits, tally, UMD, interface web | à concevoir |
| Réalisation, mixage… | Modules futurs | — |
